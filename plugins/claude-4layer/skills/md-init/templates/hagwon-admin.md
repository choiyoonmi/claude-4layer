# <학원 이름> 행정 문서 작업 폴더

<한 줄: 이 폴더에서 무엇을 만드는가. 예 — 월간 수업 안내문·상담 자료·학부모 공지를 만든다.>

## 하지 말 것

- 학생 실명·연락처·성적을 **외부 서비스로 전송하지 않는다.** 파일 안에서만 다룬다.
- 학부모에게 나가는 글은 **내가 확인하기 전에 발송하지 않는다.** 초안까지만 만든다.
- 학생 개인을 특정해 부정적으로 서술하지 않는다. 지적은 행동 단위로, 대안과 함께.

## 말투

- 존댓말. 문장은 짧게.
- 단정하지 말고 여지를 둔다. "못합니다" 대신 "아직 익숙하지 않습니다".
- 성과는 구체적 행동으로 쓴다. "열심히 했습니다" ✕ → "매일 낭독 과제를 빠짐없이 냈습니다" ○
- <그 밖에 내 말투 특징을 여기에. 예: 느낌표는 두 개씩, 딱딱한 공문 투 금지>

## 문서 규칙

- 분량: 안내문 A4 1장, 상담 자료 A4 2장을 넘기지 않는다.
- 날짜는 `2026년 3월 4일(수)` 형식. 요일을 뺀 채 쓰지 않는다.
- 금액은 `150,000원`처럼 세 자리 쉼표.
- 파일명: `<과목>_<대상>_<YYYYMM>_<문서종류>.확장자`

## 작업 방식

- 새 문서는 이 폴더의 **기존 같은 종류 문서를 먼저 열어 보고** 형식을 맞춘다. 처음부터 새로 만들지 않는다.
- 원본 파일은 덮어쓰지 않는다. 수정본은 날짜를 붙여 새 파일로 만든다.
- 표·목록이 세 항목 이하이면 표로 만들지 말고 문장으로 쓴다.

## 이 폴더의 사실

- <자주 쓰는 원본 파일 이름과 용도>
- <구글시트·드라이브 연동이 있으면 여기에>
