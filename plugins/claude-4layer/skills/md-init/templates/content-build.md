## 하지 말 것

- **산출물(PDF·완성 HTML)을 직접 손으로 고치지 않는다.** 항상 빌더를 고치고 다시 찍는다. 손으로 고치면 다음 빌드에서 사라진다.
- 기존 권의 조판 규격을 임의로 바꾸지 않는다. 시리즈는 **같아 보여야** 한다.
- 문항 정답을 학생용 산출물에 남기지 않는다.

## 조판 규격 (바꾸지 말 것)

- 판형 <A4 / B5>, 여백 <상하좌우 mm>
- 본문 <글꼴 / 크기 / 행간>
- 한 면당 문항 수 <n>개. 넘치면 면을 나누고 글자를 줄이지 않는다.
- <그 밖의 고정 규격 — 칸 크기, 색상, 머리말>

> 조판 규격이 20줄을 넘어가면 이 절을 `rules/조판규격.md`로 빼고 여기엔 한 줄 참조만 남긴다.

## 원고 규칙

- 지문 길이 <n>문장 고정.
- 어휘 수준은 <대상 학년> 기준. 교육과정 밖 한자어를 쓰면 괄호로 풀어 준다.
- 문항은 <쉬움→어려움 / 유형 순서> 로 배열한다.
- 소재에서 뺄 것: 특정 종교·정치, 가정 형태 단정, 외모 평가.
